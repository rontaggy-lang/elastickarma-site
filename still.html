How Still works

Still is designed to help users create intentional moments of prayer without getting trapped in noise, notifications, or mindless app use.
1

Choose your Still Space

Set a time and duration for prayer so your day includes a moment that is intentionally set apart.

2

Set distractions aside

Select the apps that usually pull your attention away. During Still Space, they can be gently held back.

3

Step away and pray

Enter a quiet space, put the phone down if you want, and return when your time of prayer is complete.

Built for prayer, not noise

Still is not a meditation app and not a productivity tool. It is a simple, faith-based space for returning to prayer.

Instead of filling the screen with metrics, content feeds, or clutter, Still keeps the experience quiet and grounded. It helps create structure around prayer while staying out of the way, so the focus remains where it should be.

Privacy and user control

Still is built around user choice, limited device-control features, and clear boundaries.

User-selected apps only

Still only applies boundaries to apps explicitly chosen by the user.

No monitoring of personal content

Still does not read messages, browsing content, or activity inside other apps.

Prayer time is user-directed

Users control when Still Space begins, how long it lasts, and what they choose to set aside.
